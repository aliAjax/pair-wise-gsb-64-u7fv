# 食品工厂HACCP控制计划与偏差处置平台

独立React前端工程，采用Fluent UI、Redux Toolkit、RTK Query、React Router、Vite和TypeScript。数据通过浏览器持久化，无需后端。

## 功能

- 生产批次、放行状态、监测点与隔离范围。
- HACCP流程图和控制矩阵，关键限值以**版本时间线**发布（生效时间、封版、结构化判定规则）。
- 关键限值更新后：生效时点之前尚未重判的旧读数先置「失效待重判」，再**按记录时点选版**重判，原结论留痕。
- 批次详情按依据版本拆分「限值前 / 限值后」监测段。
- 晚到现场补录所依据版本已失效时进入**待核队列**，核定前不改写任何结论；超限只另立偏差。
- 两个录入窗口并发提交同一控制点时，后到一方必须**重新选择依据**后再提交。
- 已判定偏差保留登记时的限值版本与结论；限值复判**另存一版**，不覆盖原版。
- 写入采用「待写队列（WAL）+ 最后完整检查点」：写入失败后刷新，只补未完成记录，各入口显示同一版本关系。
- 偏差调查、返工/报废分支、复核退回和签字；未关闭偏差阻止批次放行。
- 按时间线序号排序的审计与JSON追溯包导出（含版本时间线、监测段、待核队列）。

端口为`18464`。

```bash
npm install
npm run build
npm run dev
npm run test:timeline   # 生效时间线纯逻辑冒烟测试（38 项）
```

页面顶部状态栏可「模拟下次写入失败」，随后刷新页面观察从最后完整时间线恢复、仅补未完成记录的过程。
